# template_contract — qiji_heading（七级标题大纲模板）

> 本文件是 docx_builder 与 doc_checker 的**唯一样式依据**。模板原件 `template_src.docx` 永不修改；
> 分析依据见 `analysis.md`。契约版本：v1（2026-10-19）

## 1. 角色映射表

AI 产出内容中的语义角色 → 模板样式。builder 只允许通过本表赋样式。

| 语义角色 | styleId | 样式名 | 对应输入标记 |
|---|---|---|---|
| `doc.title` | 17 | Title | 文档主标题 |
| `h1`–`h7` | 2/3/5/6/7/8/9 | heading 1–7 | `#`–`#######` |
| `body` | 4 | 9 正文格式 | 普通段落 |
| `bullet` | 1 | Normal + numId=7 圆点 | `- ` 列表项 |
| `figure` | 36 | 10 图片格式 | 图片块本体 |
| `fig_caption` | 23 | 6 图名格式 | `:::caption 图` |
| `table_caption` | 33 | 7 表头格式 | `:::caption 表` |
| `table_cell` | 31 | 8 表格文字 | 表格单元格 |
| `table` | 19 | Table Grid | 表格块（普通简单全框线表，100% 宽；2026-10-19 用户指定，替代原 51 三线表蓝色样式） |
| `toc_l1/2/3` | 15/16/12 | toc 1/2/3 | 目录域生成（builder 写，AI 不写） |
| `footer` | 13 | footer | 页脚（模板内置，不动） |

默认禁用样式（checker 报 blocking）：`小标题6`–`小标题10`（30/40/41/44/46，演示用彩色样式）、`表格文字`（49，旧版残留，用 31）。
`heading 8`/`heading 9` 存在但默认不启用（工程报告 7 级足够，7 级以下走手动序号）。

## 2. 编号契约

1. **标题编号**：h1–h7 由 numId=1 自动多级编号生成（`1.` / `1.1.` / … / 七级）。
   - builder 生成标题段落时**不带任何编号文本**，样式自动编号；
   - AI 正文中引用章节写"见 3.2 节"这类纯文本，由 checker 对照实际编号核对一致性（advisory）。
2. **图表编号**：`图<章>.<节>-<序>` / `表<章>.<节>-<序>` 由样式自动生成。
   - AI 题注只写标题文字（如 `流域水系概化图`），**编号前缀禁止手打**（blocking）；
   - 交叉引用图/表时用 REF 域（builder 生成书签+域），AI 标记 `{{ref:fig:slug}}`。
3. **7 级以下正文序号**：手动输入 `（1）` → `1)` → `①` → `a)` → `●`，**不使用自动编号**（模板明令，为跨文档汇总不串号）。
4. **页码**：页脚居中 PAGE 域（模板内置）。

## 3. 硬性约束（doc_checker 条款）

| # | 条款 | 级别 |
|---|---|---|
| C1 | 所有段落样式 ∈ §1 白名单 | blocking |
| C2 | 中文字体只许 宋体/黑体；西文只许 Times New Roman（h8/h9 既有 Arial 豁免） | blocking |
| C3 | run 级直接格式白名单：加粗/斜体/上下标/字符底纹；**禁改字体、字号、颜色** | blocking |
| C4 | 标题/图表编号必须来自自动编号域，检测手打前缀（正则 `^\d+(\.\d+)*\s`、`^[图表]\d`） | blocking |
| C5 | 7 级以下序号必须是手打文本，检测到 7 级下自动编号（numId 3/4/5/6） | blocking |
| C6 | 每张图有且仅有一条图名（figure 段后紧跟 fig_caption）；表格上方有 table_caption | blocking |
| C7 | 表格样式必须为 51（三线表），表内文字必须为 31 | blocking |
| C8 | 连续空段落 >1、样式外空 run | advisory |
| C9 | 手打序号与实际标题编号不一致（"见 3.2 节"指向错误） | advisory |
| C10 | 正文段落首行缩进异常（覆盖样式缩进） | advisory |

## 4. 内容输入约定（AI 中间格式的目标）

- 图片：嵌入型（inline），不走浮动
- 题注：图名在图**下**、表题在表**上**（模板既定）
- 目录：builder 在第 2 节插 TOC 域（深度 3），AI 不写目录
- 每条关键数据段落带来源行（fact_id 对账，由 builder 转脚注或文尾来源表——交付形态待定）

## 5. 已知豁免

- heading 1 无显式 outlineLvl：builder 写入 h1 段落时显式补 `<w:outlineLvl w:val="0"/>`（不改样式表）
- 图名/表头样式自带 outline_lvl=6：保持原样，TOC 深度 3 不受影响；将来做图目录/表目录时为特性
